# Моделирование колебаний маятника (Python)

Перенос лабораторной работы из Excel в Python: модель свободных и затухающих колебаний маятника.

## Задача
Построить модель колебаний маятника без сопротивления и с сопротивлением, сравнить их и изучить влияние коэффициента сопротивления *k* на затухание.

## Что сделано
- расчёт собственной частоты, коэффициента затухания, амплитуд;
- графики свободных и затухающих колебаний с огибающей;
- сравнение колебаний при разных значениях *k*;
- таблица характеристик (период, время затухания до 5%) на pandas.

## Результаты
- чем больше сопротивление, тем быстрее затухание и тем больше период колебаний;
- при k = 0.05 колебания затухают до 5% от начальной амплитуды примерно за 1.8 с;
- при слишком большом затухании колебаний нет (апериодический режим).
